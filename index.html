What it actually does

NetShield checks every tab in the background. It doesn't just block a few known sites; it reacts to the words you gave it.

Closes the page

If a blocked word shows up in a page's address or title, or in the video you're watching, the tab closes within a second.

Hides single videos

On YouTube and similar sites, only the matching videos disappear from search results and recommendations. The rest of the page keeps working.

Closes repeat offenders

If a page keeps surfacing blocked content, 5 hits within 10 minutes, the whole tab closes.

Understands Hebrew too

Words and phrases work in any language, and it ignores things like hidden characters and nikud that people use to sneak past filters.

Hard to switch off, on purpose.

Most filters are one click from being disabled. This one adds friction exactly where willpower runs out.

The word list only grows

You can add words whenever you like. You can't remove them. Delete a line from the file and it comes right back.

One browser only

Open Edge, Firefox, Brave or regular Chrome and it closes immediately. "Chrome Filtered" opens in its place, with the link you clicked.

Uninstalling takes 3 minutes

Removal starts a 3-minute countdown, then asks you to confirm. Closing the window cancels it. If you still want it gone after that, it's gone.

A filter you can switch off at 11pm isn't much of a filter.

Set up in about a minute

  1. Download

    Get the ZIP and extract all of it. Don't run it from inside the ZIP.

  2. Run install.bat

    If Windows says "protected your PC", click More info, then Run anyway. The app isn't digitally signed.

  3. Add your words

    Use the "TabFilter Add Word" shortcut on your desktop. New words work within seconds.

  4. Open Chrome Filtered

    Always use the new desktop shortcut. NetShield starts with Windows by itself.

Questions

Does it work on Mac, phone or other browsers?

Not yet. NetShield is for Windows and Google Chrome only, so Chrome needs to be installed.

Does it send my browsing anywhere?

No. It runs on your computer, doesn't need an account, and your word list is stored locally.

Is it a virus? Windows warned me.

No. The warning appears because the app isn't digitally signed yet, which is common for small free tools.

Can I add a word later?

Yes, any time. Just not remove one. Choose words you're sure about.
